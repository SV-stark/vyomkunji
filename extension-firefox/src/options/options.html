Signer India G2C — Settings

The extension talks to the native host signer-host.exe, which signs via the GUI.

Supported portals

  • Income Tax (incometax.gov.in) — priority
  • GST (gst.gov.in)
  • MCA (mca.gov.in)
  • EPFO (epfindia.gov.in)
  • TDS (tdscpc.gov.in) / TRACES (traces.gov.in)

Prerequisites

  1. Install the Signer GUI (gui.exe) and keep it running.
  2. Register the native messaging host (see native-app/install-host.ps1).
  3. Attach your DSC token (e.g. ProxKey) — no drivers needed beyond the PKCS#11 module.

PKCS#11 module

Auto-detected: C:\Windows\System32\Watchdata\PROXKey CSP India V3.0\WDPKCS.dll

Override by setting environment variable SIGNER_PKCS11_MODULE.
